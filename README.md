# SmashPro Badminton Store

A responsive multi-page frontend e-commerce website based on the SmashPro design concept.

## Pages
1. Home
2. Products
3. Product Details
4. Cart & Checkout
5. Payment
6. Delivery & Tracking
7. About & Contact
8. Offers (supporting page)

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Features
- Responsive navigation
- Product cards and filtering
- Product detail page
- Cart using localStorage
- Checkout form
- Demo payment selection
- Demo order/tracking flow
- Contact/enquiry form
- Premium dark + gold design

## Important
The payment page is a frontend demo and does NOT process real payments. For production, connect a real payment gateway and backend/database.
